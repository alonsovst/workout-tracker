# Workout Tracker

A mobile-first workout timer app built as a single HTML file — no install, no dependencies, just open it in your browser.

## What it does

Guides you through a structured calisthenics session across 5 blocks:

1. **Warm-up / Shoulder Prep** — Dead Hang, Scapular Pull-ups, Australian Rows, Cable Wide Pull
2. **Back + Biceps** — Pull-ups, Chin-ups, Behind-the-neck Pull-up
3. **Chest + Triceps** — Bench Dip, Elevated Push-ups, Dumbbell Press
4. **Core / Abs** — Leg Raises, L-sit Hold, Toes to Bar
5. **Power Finisher** — Explosive Pull-ups, Burpees, Bar Hang to Failure

## How it works

- Each exercise runs on a **work / rest timer** (configurable per exercise)
- The **timer panel** counts down with a progress ring and phase badge (Work / Rest)
- **Alarm sounds** fire at each phase transition — a lower beep (600Hz) when rest starts, a higher beep (800Hz) when the next set begins
- Completed blocks **collapse automatically**; the next block opens
- A **progress bar** tracks overall session completion
- Use **Skip** to jump to the next exercise, **Done** to manually complete a set, or tap any exercise in the list to jump directly to it

## Audio on iPhone

Tap **Enable Sound** when the page loads. Make sure your Ring/Silent switch is set to ring.
